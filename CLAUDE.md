# CLAUDE.md — Audit Analytics Workbench

## What this project is
A local-first, open-source toolkit for audit data analytics. The design is in
`docs/design/2026-11-14-v0.1-design.md`; read it before changing behaviour.

## Hard rules
1. **Git:** commit locally in small steps. Never push, add a remote or change repository visibility without the maintainer's explicit say. Before any push, check that no real data, `private/` content or non-sample `*.csv`/`*.xlsx` is in the commits.
2. **No real data.** Use only synthetic data generated by `tools/generate_synthetic.py`. Never copy or reference real client or employer data in tracked files. Never commit anything in `private/`, `data/`, `input/` or `output/`. Real extracts and their mappings stay in those gitignored folders and are run by the user, locally.
3. **Offline.** The tool must not make network calls, send telemetry, or call any AI service at runtime. Do not add dependencies that do. The test suite must include a check that a full run opens no network connections.
4. **Human decides.** The tool flags and ranks exceptions. It must never fill in a disposition, conclusion or sign-off field.
5. **No silent changes to data.** Every coercion, placeholder conversion, rejected row or skipped test is logged and shown in the workpaper. Do not let pandas convert `N/A` to null without recording it.
6. **Reproducible.** Same input and parameters give the same output. Use fixed seeds and record them.
7. **Extensible by folder.** A new test is a folder with `test.sql` and `meta.yaml`. Do not require engine changes to add one.

## Working style
- Commit locally in small steps with clear messages.
- Write or update tests with each change; run `pytest` before saying a step is done.
- Before building something new, state what you will build and the acceptance check it must pass.
- If a decision is not covered by the design doc, ask the maintainer rather than guessing.
- Keep dependencies minimal and pinned.

## Definition of done
See the acceptance criteria in the design doc (§5.11). Do not claim done until they all pass.
