# Audit Workbench v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (chosen: inline) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CLI that validates a two-layer mapping, loads CSV/Excel sources as text, runs an integrity gate, runs SQL test packs in a locked DuckDB, bands exceptions against materiality and writes an Excel workpaper plus a deterministic `exceptions.jsonl`.

**Architecture:** `mapping` (parse + validate) → `loader` (text in, typed DuckDB tables out, every conversion counted) → `integrity` (checks on datasets) → `runner` (per-run role views, bound params, SELECT-only pack SQL in a sandboxed connection) → `materiality` → `workpaper` / `runlog`. `pipeline.run_workbench` wires them; `cli` is argparse over it.

**Tech Stack:** Python ≥3.11, duckdb==1.5.6, pandas==3.0.5, openpyxl==3.1.5, PyYAML==6.0.3, pytest==9.2.0.

**Spec:** `docs/design/2026-11-14-v0.1-design.md`

## Global Constraints

- No network calls at runtime; DuckDB `enable_external_access=false`, extension autoinstall/autoload off, `lock_configuration=true` before any pack SQL.
- Amounts are `DECIMAL(18,2)` end to end; Python side uses `decimal.Decimal`; never `float` for money.
- Sources read as text; `null_placeholders` (default `["N/A", ""]`) converted explicitly and counted per column.
- Missing mapped column → dataset rejected (gate fail). Extra columns never loaded; names logged as ignored.
- The tool never writes the `Disposition`, `Reviewer note`, `Reviewed by`, `Date`, preparer or reviewer fields.
- Gate fail stops the run unless `--force`; force recorded in run log, Cover and Integrity.
- Same input + params ⇒ byte-identical `exceptions.jsonl` (no timestamps, sorted).
- New test = folder with `meta.yaml` + `test.sql`; no engine change.
- Only generated files in `sample_data/` are tracked. No reference to any real dataset in tracked files.
- Materiality defaults: overall 50000, performance_pct 0.75, clearly_trivial_pct 0.05.
- PAY-01 tolerance 1.00; JE-01 round_to 1000, min_amount 10000, weekend_days [6, 7] (ISO: Sat=6, Sun=7); balance tolerance 0.01; balance fail message contains "possible incomplete extract".
- Disposition list exactly: `Error`, `Irregularity — inquire`, `Needs client query`, `False positive`, `Accepted`.

## Review Focus

1. Client text beginning with `=`, `+`, `-`, `@` written to the workpaper must stay literal text, never a formula (formula injection). → Task 13 test `test_formula_like_text_is_literal`.
2. Amount text with thousands separators (`1,234.50`) or currency symbols must be counted as unparseable (gate fail), not silently mis-read. → Task 4 test `test_thousands_separator_is_unparseable`.
3. Dates given as text in a non-ISO form (`05/01/2025`) must fail unless the column declares `format:`; with `format: "%d/%m/%Y"` they parse. → Task 4 test `test_date_format_declared_and_undeclared`.
4. Header with stray whitespace (`"SaleDate "`) must produce a validation error that names the near-match. → Task 3 test `test_missing_column_suggests_near_match`.
5. Run IDs that are invalid Excel sheet names (>31 chars, `[]:*?/\`) or duplicated must be rejected by `validate-mapping`. → Task 3 test `test_bad_run_ids_rejected`.

### Task 4: Loader + sandbox

**Files:** Create `workbench/sandbox.py`, `workbench/loader.py`, `tests/test_loader.py`, `tests/conftest.py` (fixture writers for small CSV/XLSX).

**Interfaces — Produces:**
- `sandbox.connect() -> duckdb.DuckDBPyConnection`; `sandbox.lock(con) -> None` (four SETs, in that order).
- `loader.load_datasets(con, mapping: dict, base_dir: Path) -> LoadResult`
- `@dataclass LoadResult: files: list[FileInfo], datasets: dict[str, DatasetLoad]`
- `@dataclass FileInfo: path (str as written in mapping), sha256, size, modified (ISO UTC)`
- `@dataclass DatasetLoad: name, status ("loaded"|"rejected"), reason, source_rows, loaded_rows, rejected_rows: list[(row_no, reason)], blank_rows_skipped, ignored_columns: list[str], placeholders: dict[col,int], nulls: dict[col,int], unparseable: dict[col, list[row_no]], coercions: list[str]`; table name in DuckDB is `ds_<name>`.
- CSV via `csv.reader` (UTF-8-sig): rows whose field count ≠ header count are rejected (row number + reason). Excel via openpyxl read-only: cell → text (`datetime`→ISO date or datetime, `int`→str, `float`→`repr`-based shortest text, counted as coercion "excel number → text" per column); fully blank rows skipped and counted.
- Types converted in DuckDB from text: decimal `TRY_CAST(... AS DECIMAL(18,2))`; integer `BIGINT`; date `TRY_CAST(TRY_CAST(x AS TIMESTAMP) AS DATE)` or `TRY_STRPTIME(x, format)` when `format` declared; boolean from `true/false/yes/no/1/0` (case-insensitive). Non-null text that fails → row listed in `unparseable`.
- Optional `expected_rows` on a dataset: compared later by the gate.

- [ ] Tests: `test_placeholders_counted_not_silent`, `test_extra_columns_ignored_and_logged`, `test_missing_column_rejects_dataset`, `test_csv_short_row_rejected`, `test_thousands_separator_is_unparseable`, `test_date_format_declared_and_undeclared`, `test_decimal_type_is_exact` (typeof = DECIMAL(18,2)), `test_sandbox_blocks_file_read`.

### Task 5: Integrity gate

**Files:** Create `workbench/integrity.py`, `tests/test_integrity.py`.

**Interfaces — Produces:**
- `run_gate(con, mapping: dict, load: LoadResult) -> GateResult`
- `@dataclass Check: dataset, check, status ("info"|"pass"|"warn"|"fail"), detail: str, value: str | None`
- `@dataclass GateResult: checks: list[Check], status ("pass"|"warn"|"fail")`, `.failed -> bool`.
- Checks per design §5.6: file hash info; dataset rejected (fail); source vs loaded rows + rejected rows (fail if differ); `expected_rows` mismatch (fail); duplicate PK (fail, count + up to 20 keys); unparseable (fail); balance_check (fail, detail starts "Unbalanced: possible incomplete extract"); control totals (info: sum per decimal column or declared list, min/max per date column, distinct PK count); placeholders (warn if >0) / nulls (info) with %; references both directions (orphans warn; childless parents info unless `require_children: true` → warn); sequence gaps (warn, gap count + up to 50 IDs).

- [ ] Tests: one per fail type (missing column, duplicate key, truncated CSV, unbalanced JE, expected_rows mismatch), `test_orphans_warn_not_fail`, `test_sequence_gaps_listed`, `test_clean_dataset_passes`.

### Task 7: Runner

**Files:** Create `workbench/runner.py`, `tests/test_runner.py`.

**Interfaces — Produces:**
- `run_packs(con, mapping: dict, packs: dict[str, Pack], load: LoadResult, base_dir: Path) -> list[RunResult]`
- `@dataclass RunResult: run_id, pack: Pack, status ("ok"|"skipped"|"failed"), reason, exceptions: list[dict], params: dict, systemic: str | None`
- For each run: if a bound dataset isn't loaded → skipped (reason). Create `TEMP VIEW <role>` = contract fields renamed + `field_list` fields passed through. - Exceptions are dicts of JSON-safe values: Decimal → str, date → ISO str, None stays None.
